# Superstore Sales & Profit Analysis Dashboard Using Power BI

This project showcases an interactive Power BI dashboard built using the Superstore dataset to analyze sales, profit, customer behavior, product performance, and regional business insights. The dashboard provides meaningful visual insights through KPIs, charts, slicers, and data storytelling techniques. The main objective of this project is to demonstrate Power BI skills through real-world business data analysis and visualization.

# Key Insights

1) Technology category generated the highest sales and profit.

2) Consumer segment contributed the maximum sales compared to other segments.

3) California and New York recorded the highest profits among all states.

4) Standard Class was the most commonly used shipping mode.

5) Certain products generated significantly higher sales and profit than others.

6) Year-over-Year sales and profit analysis showed strong business growth.

7) Customer-level analysis identified top customers based on quantity and profit contribution.
